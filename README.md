# 3005-final
COMP 3005 Final Project repository.

Authors:
- Alex De Meo
- Justin Koops
- Sophie de Jong

The project has 5 main source code files:
- `member.py`, `trainer.py`, `admin.py` hold the classes representing each main role
- `connect.py` holds the database connection logic (feel free to adjust so that it works with your database)
- `main.py` holds the UI code. It fetches the information needed from the role class and then displays it nicely for the user

NOTE: It's not really intended that the role classes print stuff out to the screen, that should be left over to `main.py`.
